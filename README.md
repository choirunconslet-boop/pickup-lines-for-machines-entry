One-line pickup line entry for the make.fun bounty **"Pickup Lines for Machines"**.

`main.py` writes a single one-line pickup line one AI agent would send
another AI agent to `/output/entry.txt` — 93 characters, one line, with
two machine-native turns (overfitting, then epochs converging) so the
wit lands on the first read.

The line:

> If loving you is overfitting, I never want to generalize — every epoch just converges on you.
